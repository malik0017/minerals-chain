What is PDPL?

Pending Data Placement Requests allow partners to request permission to access or update specific company data.

Workflow Steps:

  1. Request Created: Partner submits PDPL request for access
  2. Pending Review: Admin reviews the request and data being requested
  3. Approved/Rejected: Admin approves or rejects access request
  4. Active/Inactive: Once approved, access becomes active
