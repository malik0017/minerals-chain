Fixing .env items — step by step
  1. Stop the server
    Press Ctrl+C in the terminal running uvicorn{% if is_production %} (or sudo systemctl stop minerals){% endif %}.
  2. Open the .env file
    {% if is_production %}In the app folder on the server, e.g. /srv/minerals/app/.env.{% else %}C:\laragon\www\minerals\.env — same folder as requirements.txt.{% endif %}
  3. Apply the changes — pick one
    Automatic (keeps a backup of the old file):
    python scripts/harden_env.py --profile {{ 'production' if is_production else 'local' }}
    Or copy the lines on the right into .env, replacing any existing line with the same name.
  4. Start the server again
    {% if is_production %}sudo systemctl start minerals{% else %}uvicorn app.main:app --reload{% endif %}
  5. Reload this page
    Fixed items turn green and the score goes up.

{% endif %}
