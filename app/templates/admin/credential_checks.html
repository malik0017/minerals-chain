What a registry check does
  1. Takes the number the company registered with
    CR number for every company; mining licence number for sellers.
  2. Looks it up at the government source
    Wathq (Ministry of Commerce) for the Commercial Registration, MIM (Ministry of Industry & Mineral Resources) for the mining licence.
  3. Compares the record with what the company typed
    Record exists → active → not expired → registered name matches the company name (≥ 72% similar).
  4. Stores the result on the company
    Shown here, on the approval review and on the company page. A verified MIM licence also marks the company's licence as verified and sets its expiry date.
Runs automatically when a company registers (System settings → “Check CR / licence automatically”). Companies created by seed/demo scripts skip registration, so run Check unchecked companies once.
Modes (.env)
sandbox
Simulated answers — no API key, nothing leaves the server. Use for testing.
live
Calls the real API. Needs WATHQ_API_KEY (and MIM_API_URL / MIM_API_KEY).
off
Checks disabled.
