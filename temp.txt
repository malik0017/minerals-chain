CURRENT STATE
──────────────────────────────────────────────────────────────
Working end-to-end, verified against real Postgres, every batch:
  - Registration (seller/buyer/lab) + admin approval workflow
  - Login/logout, session cookies, portal role isolation
  - Real per-portal dashboards on the actual vendor theme, real data
    wired in (not a simplified shell) — admin preview shows genuine
    platform-wide totals, not hidden/zero stats
  - Admin can view any portal's dashboard directly (no re-login), with
    a clear preview banner + header label ("Admin Portal · Previewing
    X Portal")
  - Admin has full oversight: /admin/companies (any status, drill-in
    with listings/verification/passports or certificates),
    /admin/users (every account), /admin/passports (approval queue) —
    BRD §6.8
  - Company-scoped pages (seller listings, lab verification) redirect
    admin to the equivalent oversight view instead of a blunt 403
  - Self-service profile: name, password, avatar upload/remove — any
    logged-in user
  - In-app notifications
  - Seller product listings: create, list, view, edit (while draft/
    failed_verification), per-company ownership enforcement
  - Lab verification workflow end-to-end: request -> lock listing ->
    lab issues Certificate (-> VERIFIED) or rejects (->
    FAILED_VERIFICATION, editable again) -> notifications both ways
  - Mineral Passport workflow end-to-end: seller requests on a
    VERIFIED listing -> admin approves (generates passport number +
    12-month validity) or rejects -> public no-login lookup at
    /passports/verify confirms authenticity
  - Both recurring theme 404s fixed (logo.png, bootstrap-icons.woff2)
  - Git repo pushed to a private GitHub remote

Known cleanup still pending (low priority, doesn't block anything):
  - Delete app/templates/layouts/base_app.html and base_portal.html
  - Delete app/modules/seller/routes.py (stray unused duplicate)

Deliberate scope boundaries (not gaps — noted so they don't get
re-litigated by accident):
  - Email is not editable from /my-profile or /admin/users
  - Company role is not editable anywhere
  - Passport validity period (365 days) is a hardcoded constant, no
    admin-configurable policy UI
