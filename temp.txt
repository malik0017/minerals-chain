OPERATIONAL REMINDER (learned the hard way — see the 0007 note above)
──────────────────────────────────────────────────────────────
Every delivery that includes a new file under alembic/versions/ needs
`alembic upgrade head` run against the actual database after copying
the files in. Copying the migration file alone does NOT apply it — if
you see a "column ... does not exist" error right after applying a
batch, this is almost always the cause. Check `alembic current` vs the
latest filename in alembic/versions/ to confirm before doing anything
else.
